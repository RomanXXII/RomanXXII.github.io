# RomanXXII.github.io

Personal portfolio site for Roman Beames, hosted with GitHub Pages.

## Structure

- `index.html` - one-page portfolio content and semantic page structure
- `style.css` - global design tokens, layout, responsive styles, and components
- `assets/` - project-local visual assets used by the site

The site is intentionally static HTML/CSS for now so it remains simple to deploy and easy to migrate later.
